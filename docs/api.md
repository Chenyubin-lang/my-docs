# API 参考

本页面展示一个模拟 API 接口，仅用于文档编写练习，不提供真实服务。

## 获取文档列表

请求方法：`GET`

请求路径：`/api/docs`

### 响应示例

```json
{
  "items": [
    {
      "id": 1,
      "title": "使用指南"
    },
    {
      "id": 2,
      "title": "API 参考"
    }
  ]
}
```

## 字段说明

| 字段 | 类型 | 描述 |
|---|---|---|
| id | Integer | 文档编号 |
| title | String | 文档标题 |
