# 关于本项目

## 项目介绍

这是一个用于学习 GitHub Actions 自动化部署技术的实践项目。

## 技术组成

| 技术 | 作用 |
|---|---|
| Markdown | 编写文档内容 |
| MkDocs | 生成静态网站 |
| Material | 提供网站主题 |
| GitHub Actions | 自动构建与部署 |
| GitHub Pages | 托管静态网站 |

## 实践目标

理解从 Markdown 源文件到公开网站的完整部署流程。
## 本次实践体会

本项目把“编写文档”和“发布网站”分成两个环节：平时维护 Markdown 源文件，发布时由工作流生成静态页面。我在检查中发现，即使工作流已经被识别，也需要先开启仓库的 Pages 功能；源码上传成功并不代表网站已经发布成功。构建产物不应手工修改，后续更新应从 docs/ 开始。
